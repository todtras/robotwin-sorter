# 라벨링 규칙

> 3명이 **동일하게** 지켜야 합니다. 사람마다 다르게 라벨링하면 모델이 혼란스러워하고,
> 원인을 나중에 찾기가 매우 어렵습니다.

## 기본 규칙

1. 바운딩박스는 **물체에 딱 맞게.** 여유를 두지 마세요.
2. **일부만 보이는 물체도 보이는 부분만** 박스 처리합니다.
   아예 빼면 모델이 "여긴 아무것도 없다"로 학습해 버립니다.
3. 물체가 화면 가장자리에 **절반 이상 잘려 있으면 그 이미지는 폐기.**
4. 애매한 것은 **즉시 팀에 물어보고, 결정을 아래 표에 기록.**

## 클래스 정의

> ★ ID 순서는 `can → general → pet` (알파벳순)입니다. Roboflow가 클래스를
> 알파벳순으로 강제 정렬해서 내보내기 때문에, 실제 학습 데이터의 클래스 ID가
> 이 순서로 고정됩니다. `common/schema.py`의 `CLASS_NAMES`, `dataset/data.yaml`의
> `names`와 반드시 일치시키세요.

| ID | 클래스 | 포함 |
|---|---|---|
| 0 | `can` | 알루미늄 음료캔, 통조림캔 |
| 1 | `general` | 종이컵, 과자봉지, 비닐, 티슈, 일회용 수저 |
| 2 | `pet` | 투명 페트병(라벨 유무 무관), 플라스틱 음료병 |
